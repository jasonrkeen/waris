# Full research release assembly

The release target remains the full research package after all checks. rc5 is an unreleased source review candidate. Nothing in this procedure publishes, pushes, sends, uploads or authorizes a release.

## Prepared locally

The candidate contains repaired source, the locked dependency snapshot, offline demonstration, regression tests, model card, update-guide assessment, third party notices, source-reference annotations and provider/indicator records. The separate preparation pack contains the 175-artifact rights ledger, current source evidence, quarterly numerical reconciliation, World Bank snapshot comparison and release specification.

The full distribution can contain verified methods, approved aggregate research outputs and acquisition instructions for restricted inputs. Restricted raw inputs can remain private and be independently acquired by authorized researchers. Do not replace the full research target with a synthetic-only demonstration or represent omitted raw data as publicly redistributable.

## Complete the frozen evidence run

1. Create an isolated validation copy; retain Research-1 originals and rc1-rc5 archives. Configure fresh ACLED credentials privately. The Research-1 credential file was stale at the October 13 check; post-rotation status remains unverified.
2. Complete release_specification.json with exact query periods, ACLED sampling/export and pagination policy, account/use entitlement, seed, simulations, code/dependency hashes and cache policy. The known NBU historical date is 20240101; a newer date requires a separate specification.
3. Retain private provider responses with UTC retrieval times, sanitized requests, hashes, source units/statuses, pagination and completeness. Never record authorization headers, token bodies or credentials. Record unavailable sources and cache hits truthfully.
4. Verify annual FIU claims at exact pages; resolve the quarterly label/denominator caveat; verify dataset exceptions, identifiers, wartime limitations and all required notices. Review each selected file's complete contributing-source chain.
5. Run the complete pipeline, freeze all inputs and outputs, and replay without provider access. Compare keyed calculations at declared tolerance and reconcile every other research artifact. Historical core replay already passed separately; it is not complete acquisition/output replay.
6. Inspect every final PDF page and figure, including visible source attribution, filters, actual access dates, transformations and interpretation limits. Complete intended-platform CI and independent methodological review. The prior local tests do not substitute for these gates.

## Assemble the final directory

Use an explicit inclusion list. Include code/docs, environment lock, model card, third party notices, source/acquisition register, run specification and manifest, approved research outputs, reproducibility instructions, limitations and validation record. Mark each included artifact with its hash, rights basis, required credit, transformations, source dependencies, privacy decision and reviewer decision.

Exclude credentials, tokens, virtual environments, caches, unreviewed attachments, restricted event/entity exports and uncleared derivatives. Raw-event removal alone does not clear derivative rights. Preserve separate provider licenses; MIT applies to code.

Before ZIP creation, check the actual included files against the inclusion list, re-scan for secrets, verify source-boundary flags and final hashes, and confirm no temporary files or stale outputs are present. Keep publication status explicitly unreleased. Publication requires a separate later user instruction.
