# WARIS selected candidate, parser and availability preparation supplement

Prepared locally on 20 October 2026; unpublished. GRP remains benchmark-only. No production scoring, sector allocation or Monte Carlo integration is approved. Unverified FIU annual-report claims remain excluded. Full research release is blocked.

Three byte-preserved historical CSVs are eligible only with these dated companion notes: the 18-row confirmed-series extraction, its single-oblast latest candidate and the 25-oblast candidate table. Their selected values and annual year labels match retained response content and previously cleared official GRP facts. Blank unit/update fields remain historical omissions, not unknown source units or request timestamps. Provisional NACE/frequency labels and pending/control flags are display/workflow declarations, not independent validation. source_url is a recorded locator, not an authenticated HTTP request. latest_period means latest in that retained response, not globally current latest. January-1 dates in the old extraction are normalized annual labels, not measurement-day observations.

The new typed confirmed-series and 25-candidate tables obtain years directly from explicit SDMX value/id labels, carry UAH unit code 1090 and scale 6 (millions), preserve notes and distinguish source UPDATED metadata from acquisition time. An annual label such as 2021 is kept as a year. Source UPDATED is a dataset attribute, not a collection receipt. The retained source has value labels; the legacy parser looked only at id/name and therefore used availability bounds to generate consecutive annual labels. That coincides with this contiguous 18-year series, but is unsafe for gapped/partial responses. The new decoder refuses inferred periods, conflicting labels, unsupported axes/units and observations without explicit time labels. It is scoped to the selected annual GRP shape, not universal SDMX compliance.

The 60-row availability artifact matches its retained constraint: 58 listed component values and two range boundaries. The new summary preserves cube include=true, component include=false, and range/count annotations literally, without enumerating bulk imported codes or inferring positive selectors or observed years. The annotation end 2022-01-01 does not prove a 2022 observation; selected retained observed values end in 2021. Provider-specific full constraint evaluation remains unvalidated.

All 32934 imported code/name/description facts match their retained exact-version codelists. This is internal content reconciliation, not authoritative DSD binding, query validity, current code validity or blanket rights clearance. The bulk listing remains private. Public counts identify the four codelist groups only.

All 77 flattened paths/previews match a retained response with no observations: 62 structure metadata leaves, 13 dataset attribute leaves and two dataset control leaves. A metadata path containing series is not an observed series. The raw path/preview file is excluded; a role-count summary is provided. The five-step query plan is superseded by selected-scope evidence/limitations; its old references include one absent matrix-success response, which was not reconstructed.

The original rc11 code, model weights, seeds and dependencies are unchanged. The strict decoder is a separately tested replacement component; integrating it into the application and replacing legacy period-fallback/output handling is a remaining release blocker. This supplement alone does not fix or validate the full pipeline.
