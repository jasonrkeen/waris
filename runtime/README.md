# WARIS

Ukraine Wartime AML Revenue Integrity Scoring Model — **unreleased rc13 code baseline, documentation review 1 (23 October 2026)**. This is a local source review package. Full research release is blocked; nothing has been published or pushed.

WARIS is a research prototype for studying transparent region/sector review-prioritisation architectures. Its runnable demonstration uses seeded synthetic data. Scores are not probabilities of money laundering, evidence of misconduct, operational validation or grounds for adverse action. Apparent regional/sector patterns can be generated by the synthetic assumptions themselves.

## Run the isolated synthetic demonstration

Use Python 3.12 in a new local checkout and environment:

```text
python -m venv .venv
```

Activate the environment for your shell, then:

```text
python -m pip install -r requirements-dev.txt
python offline_demo.py
python -m pytest -q
python -m streamlit run app.py
```

The demo computation denies network access and redirects model artifact paths to an empty temporary directory. It writes five clearly labelled synthetic CSVs and a synthetic-demo manifest. Installation may require network access. Optional dashboard research tabs can be empty; file availability is not verified source quality or control effectiveness. The demo does not generate the full research PDF or run all legacy research stages.
