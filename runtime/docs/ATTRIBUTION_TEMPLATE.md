# Attribution template for approved research outputs

This template is unfinished until every bracketed field is replaced with verified run evidence. Do not invent missing access dates or use a current check date as a historical retrieval date.

For each exported table, chart or report record: provider and dataset/document title; official URL; actual data-access date; reporting period and geography; series IDs, units and filters; transformation/aggregation; source license or applicable use basis; input hash and run identity; changes made by WARIS; analytical boundary; limitations.

For source-backed figures, place the source credit on the exported figure itself and keep full query/transformation details in its caption or linked register. Verify required provider wording before export. A synthetic figure must say synthetic only.

World Bank example: World Bank, World Development Indicators, [indicator ID and underlying provider credit from world_bank_indicator_rights.csv], CC BY 4.0, accessed [actual date], Ukraine, [period], [transformations].

Ukrstat example: State Statistics Service of Ukraine, Regional accounts, [exact GRP series], [year/unit/status], accessed [actual date], portal default CC BY 4.0 unless dataset exceptions apply, [transformations]. Benchmark-only; not a scoring input.

FIU example: State Financial Monitoring Service of Ukraine, [document title], [reporting period], p. [checked page], [official PDF URL], site default CC BY 4.0 unless otherwise specified; WARIS [transcription/interpretation]. National context only. State the reference caveat where applicable.

Do not imply provider endorsement or relabel restricted inputs as MIT. Validate separate rights and figure requirements before completing this template for other providers.
