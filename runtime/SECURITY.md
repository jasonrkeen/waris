# Security

Do not post credentials, provider tokens, private source extracts or personal-data samples in public issues. Remove sensitive values from diagnostics. Report suspected exposure through the repository owner's private security-reporting channel once configured; no contact endpoint is invented here.

Keep provider credentials in a local ignored `.env`. Rotate any credential previously distributed in an archive. Review dependency advisories before each release. The current local snapshot passed a known-advisory scan at audit time; this is not a guarantee against undisclosed vulnerabilities.
